## 🌟 The Vision: A Game-Changer Built by a Solo Developer

Creating video games has always been one of the most creatively rewarding yet brutally difficult pursuits in software engineering. For solo indie developers around the world, building commercial games for major storefronts like **Steam** and **Meta Horizon Worlds** typically requires entire teams of level designers, physics mathematicians, narrative writers, and security auditors.

**MetaHorizon Odyssey** is a breakthrough autonomous AI game development engine and playable 60 FPS multi-tier action RPG created to change this reality forever. Built natively from the ground up during the Meta Global AI Developer Hackathon (Oct 26 – Nov 4, 2026), it directly bridges Meta's most advanced frontier AI models into game development:

1. **Meta Muse Code 1.4 & Muse Spark**: Autonomously synthesizes procedural room architecture, balanced enemy waves, and dynamic physics equations on the fly.
2. **Meta SAM 3 (Segment Anything 3.1)**: Solves the hardest problem in 2D/3D sprite physics by performing zero-shot segmentation to extract watertight convex collision hitboxes directly from raw artwork.
3. **Meta Llama 3.2 90B Vision / Glimmer**: Procedurally generates context-aware NPC dialogues, emergent quest chains, and lore across 4 progressive tiers.
4. **Meta Llama Guard 3 & Prompt Guard**: Protects multiplayer games in real time against toxic behavior, hate speech, and prompt injection attacks.
5. **Meta CyberSecEval 3**: Audits all generated game scripts and prevents exploits, buffer runaway, and secret credential leaks (scoring **Grade A+ 100/100**).
6. **One-Click Dual Publishing**: Automatically exports deployment packages for both **Meta Horizon Worlds** (scene manifest JSON) and **Steam** (App manifest).

## ⚡ Quick Start & How to Play

### 1. Prerequisites & Installation

MetaHorizon Odyssey runs **100% natively on Windows 10/11 with zero WSL requirements**.

```powershell
# Clone the public repository
git clone https://github.com/PinoyUnknown/Meta-AI-Hackathon-2026-Project.git
cd Meta-AI-Hackathon-2026-Project

# Install dependencies (Pygame, CustomTkinter, FastAPI, etc.)
pip install -r requirements.txt
```

### 2. Launch the 60 FPS Playable Game

```powershell
python main.py
```

#### In-Game Controls:
- **WASD / Arrow Keys**: Move the Cyber-Guardian.
- **Mouse Cursor**: Aim directional blaster.
- **Left Mouse Click**: Fire kinetic blaster / plasma wave.
- **SPACE**: **Phase Dash** (gives invulnerability frames + speed burst).
- **TAB / G Key**: Open the **Meta AI Game Forge In-Game Drawer** to inspect real-time procedural code, SAM 3 hitboxes, and active Meta AI models!
- **ESC**: Pause / Quit.

### 3. Alternative Launch Modes

```powershell
# Run the interactive Meta AI Game Forge pipeline in the console
python main.py --cli

# Export Meta Horizon Worlds & Steam manifests to dist_game_export/
python main.py --export

# Launch the Native Desktop Game Dev Studio (CustomTkinter GUI)
python main.py --studio

# Launch the WebGL 3D Game & FastAPI server on http://127.0.0.1:8000
python main.py --web

# Run the automated 7-point validation & model benchmark harness
python main.py --benchmark

# Run the Meta CyberSecEval Grade A+ security & credential audit
python main.py --security
```
