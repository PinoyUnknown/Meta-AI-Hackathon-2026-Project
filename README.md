## ⚡ Quick Start & Installation

### Prerequisites
- **Python 3.10+**
- **Windows 10 / Windows 11**, macOS, or Linux
- *(Optional)* Meta Muse Code CLI (`muse`)

### 1. Clone & Install
```bash
git clone https://github.com/PinoyUnknown/Meta-AI-Hackathon-2026-Project.git
cd Meta-AI-Hackathon-2026-Project
pip install -r requirements.txt
```

### 2. Launch Master Interfaces

#### **Option A: Native Desktop GUI (Windows 10/11)**
```bash
python main.py
```
*Launches the high-tech CustomTkinter desktop HUD with real-time model chips, interactive canvas, and 1-click sandbox execution.*

#### **Option B: FastAPI Web Server & 3D WebGL Studio**
```bash
python main.py --web
```
*Starts the FastAPI backend on `http://127.0.0.1:8000` and opens the interactive Three.js 3D viewport.*

#### **Option C: Interactive Terminal Demo HUD**
```bash
python main.py --cli
```
*Executes the complete 5-stage superintelligence stream with live terminal telemetry.*
